ICT461 Course Registration Portal

A simple web application for registering students for courses.

What the System Does

The system allows users to:

• View available courses
• Register a student for a course
• Receive a registration ID
• Search for a registration using its ID
• Update a registration
• Delete a registration

Technologies Used

• HTML
• CSS
• JavaScript
• Node.js
• Express.js
• CORS

Project Files

• index.html – Main webpage and registration forms
• style.css – Page design and responsive layout
• api.js – Connects the webpage to the API
• server.js – Express server and API routes
• package.json – Project information and dependencies
• package-lock.json – Records installed dependency versions
• .gitignore – Files and folders excluded from Git
• README.md – Project information and instructions

How to Run

1. Install dependencies

Open a terminal in the project folder and run:

```bash
npm install
```

2. Start the server

Run:

```bash
npm start
```

The API will run at:

http://localhost:3000

3. Open the webpage

Open index.html in a browser.

The webpage connects to the Express API running on port 3000.

Main API Endpoints

Method   Endpoint                   Purpose

────────

GET      /api/courses             Gets available courses
GET      /api/registrations/:id   Finds a registration
POST     /api/registrations       Creates a registration
PUT      /api/registrations/:id   Replaces a registration
PATCH    /api/registrations/:id   Partially updates a registration
DELETE   /api/registrations/:id   Deletes a registration

Important Notes

• Registration data is currently stored in memory.
• Data is lost when the server is restarted.
• The server checks that the selected course exists.
• A student should not register for the same course more than once.
• Registration IDs are generated by the server.
