# AI Use

AI tools like ChartGPT, DeepSeek were used as a support tool during the development of this project.

## How AI Was Used

AI assistance was used to:
- Helped with coming up with the roadmap for the lab.
- Understand parts of the HTML, CSS, JavaScript and Express.js code.
- Identify possible bugs and areas for improvement.
- Explain HTTP methods such as GET, POST, PUT, PATCH and DELETE.
- Help review the registration API and its validation.
- They Suggest ways to improve the code while keeping the project simple.
- Help document the project in the README file.

## Code Changes

The final code was reviewed and edited by the project contributor.

One of the fixes made during the review was changing the registration ID generation so that IDs remain unique even after a registration is deleted.

Another planned improvement is to prevent duplicate student and course combinations when registrations are updated using PUT or PATCH.

## Responsibility

AI was only used for guidance and explanation. We as the project contributors are responsible for reviewing, understanding, testing and committing the final changes.
